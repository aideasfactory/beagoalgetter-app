## Features <a name="features"></a>

- 🔒 Authentication using Supabase
- 💸 Paywalls and Payments with Superwall
- 🤖 AI Chatbot and AI Image Generation with OpenAI
- 🚨 Error Tracking and Monitoring with Sentry
- 🔔 Notifications with Expo Notifications
- ⌨️ Form Validation with Zod and React Hook Form



## Requirements

- Node 18+
- Git 
- Expo GO
- Expo CLI
- Eas CLI
- Watchman (for macOS users)


## Getting Started

After cloning the repo and activating your license, visit [our quickstart guide](https://docs.launchyourapp.dev/quickstart) to get started.  

We’ve got everything you need to launch your app on any platform! 🚀
